怎样读规则，以及哪些内容受到支持
$[0] 表示第一个位置；对象按键、值成对遍历，<key:0> 与 <value:0> 是首对键值。键也会参与映射，命名占位符时请避免和固定字段名重复。
新数据的标量可以更换类型。重复的源样例值取首个位置，并显示提示；反向校验检查本次输入能否完整还原，不会自动补回丢失的数据。
此实验台支持 JSON。Python 库另支持 tuple、set、bytes 和可哈希字典键。浏览器对象键必须是字符串，数字字符串键按 JavaScript 属性顺序；有序数据推荐用数组。每份文档最多 200,000 字符、10,000 节点、64 层；输出预算 2,000,000 字符，整数需在浏览器精确范围内。
输入只在当前页面处理。刷新会重置示例；没有上传、账户或后端服务。
